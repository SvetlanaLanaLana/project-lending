# Лендинг имиджмейкера

Премиальный одностраничный сайт с фокусом на визуальную подачу: фиксированное меню с blur-эффектом, анимации появления контента при скролле, аккуратные карточки и мягкие hover-эффекты.

## Структура проекта

- `лендинг.html` — основной HTML-документ.
- `styles.css` — вся стилизация и визуальные эффекты.
- `script.js` — анимация появления блоков при скролле.
- `калькулятор.html` — дополнительная страница проекта.

## Запуск

1. Откройте `лендинг.html` в браузере.
2. Для корректного предпросмотра можно использовать Live Server в Cursor/VS Code.

## Что улучшено

- Фиксированная полупрозрачная навигация с blur.
- Премиальная типографика (`Inter` + `Playfair Display`).
- Брендовые градиенты и глубина через мягкие тени.
- Карточки с деликатным hover-подъёмом.
- Scroll-reveal анимации через `IntersectionObserver`.
